# Ai-chat-transit-platform
首页可以选择使用的AI模型进行聊天，后台可以添加模型密钥，以及设置会员卡密，拥有独立账号数据记录功能 ; You can choose the AI model to chat on the home page, add the model key and set the membership card secret in the background, and have the function of independent account data recording.
